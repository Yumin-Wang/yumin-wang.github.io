# yumin-wang.github.io

Personal site for Yumin Wang — served at https://yumin-wang.github.io.

- **Repo root** (`index.html`, `assets/`, `favicon.svg`) — the *built* static site. This is what GitHub Pages serves; don't hand-edit it.
- **`app/`** — the editable source (React + Vite + Tailwind + Framer Motion + D3). See `app/README.md` for how to develop and re-publish.

`.nojekyll` disables GitHub's default Jekyll processing so the Vite build's `assets/` folder is served as-is.
